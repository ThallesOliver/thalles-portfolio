# Portfólio · Thalles Oliveira

Site pessoal de Thalles Oliveira, desenvolvedor e co-fundador da [Zentra](https://www.zentrasistemas.com.br/).

**No ar:** https://thalles-oliveira.vercel.app

## O que tem no site

- Apresentação, experiência e formação, especialidades, projeto Zentra e serviços
- Currículo em PDF para baixar, em português e em inglês
- Contato direto pelo WhatsApp, com mensagem pronta
- Versão em português e inglês (botão PT/EN)
- Modo claro e escuro
- Menu que acompanha a seção na tela, também no celular
- Prévia caprichada ao compartilhar o link (WhatsApp, LinkedIn) e dados estruturados para o Google

## Tecnologias

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Hospedado na Vercel.

## Estrutura

```
index.html                      página completa (estilos e scripts embutidos)
foto.jpg                        foto de perfil (600 × 600)
zentra-mark.svg                 logo da Zentra
curriculo-thalles-oliveira.pdf  currículo em português
resume-thalles-oliveira.pdf     currículo em inglês
og.jpg                          imagem de prévia ao compartilhar o link (1200 × 630)
apple-touch-icon.png            ícone ao salvar o site na tela inicial do celular
```

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```
npx serve .
```
