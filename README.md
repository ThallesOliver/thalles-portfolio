## O que tem no site

- Apresentação, serviços (sites, apps e sistemas), experiência e formação
- Projeto em destaque: Zentra
- Especialidades: HTML5 & CSS3, JavaScript, Git & GitHub, Python
- Contato direto pelo WhatsApp
- Versão em português e inglês (botão PT/EN)
- Modo claro e escuro

## Tecnologias

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Hospedado na Vercel.

## Estrutura

```
index.html   página completa (estilos e scripts embutidos)
foto.jpg     foto de perfil
```

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```
npx serve .
```
